## Состав

Выполняются в выбранной базе, семантика полностью наследует RSVData:

| Инструмент | Назначение |
|---|---|
| `ping` | проверка связи |
| `config` | паспорт базы: конфигурация, расширения, подсистемы |
| `describe` | поиск и обзор состава конфигурации |
| `get_structure` | полная структура одного объекта |
| `query` | чтение одной таблицы без языка запросов |
| `execute_query` | произвольный запрос на языке запросов 1С |
| `eventlog` | журнал регистрации с отборами |
| `reveal` | расшифровка анонимизации ([ОРГ-00001] → реальные значения) |
| `help` | справка RSVData (`help` — обзор базы, `help topic=<имя>` — раздел) |

Схемы инструментов публикует сам роутер: при добавлении нового инструмента
в RSVData нужно добавить обёртку в `tools.py`.

## Маршрутизация: base и cwd

Каждый инструмент данных получает параметры **`base`** (алиас цели из
`targets.json`) и **`cwd`** (рабочий каталог агента). Выбор базы:

- `base` указан — вызов уходит в эту цель;
- без `base`: цель привязана к воркспейсу EDT и `cwd` лежит внутри —
  вызов уходит в эту цель;
- без `base` зарегистрирована ровно одна цель — она сама;
- иначе — отказ со списком доступных целей и подсказкой указать `base`
  или работать из каталога проекта EDT.
